## چرا Antigravity RTL؟

به طور پیش‌فرض، برنامه Antigravity تمامی بخش‌های چت، پنل مصنوعات (Artifacts) و باکس تایپ پیام را با جهت چپ‌به‌راست (`LTR`) نمایش می‌دهد. این امر در متون فارسی و راست‌به‌چپ موجب معکوس شدن علائم نگارشی، جابجایی کلمات انگلیسی وسط جملات، و شکستگی ساختار پاراگراف‌ها می‌شود.

این پروژه بدون دستکاری فونت‌های برنامه و بدون ایجاد تداخل در مکانیزم آپدیت خودکار نرم‌افزار، قابلیت **Auto-Bidi هوشمند** را به برنامه اضافه می‌کند.

---

## قابلیت‌های کلیدی

| بخش | رفتار با پچ RTL |
| :--- | :--- |
| **تشخیص پاراگرافی (Auto-Bidi)** | تنظیم خودکار جهت هر پاراگراف، تیتر و لیست به صورت مجزا (مشابه تلگرام و نوشن) بدون نیاز به تنظیم دستی. |
| **الگوریتم نحو جمله (Precision BiDi)** | تشخیص صحیح جملات فارسی که با واژه‌های انگلیسی شروع می‌شوند (مانند `Docker رو باز کن` یا `README هنوز...`) و قرارگیری کلمه در ابتدای سطر سمت راست. |
| **کدهای درون‌خطی و بک‌تیک (`code`)** | حفظ جهت راست‌به‌چپ برای جملات فارسی داخل بک‌تیک، و حفظ کامل جهت چپ‌چین برای کدهای فنی خالص (`npm`, `git`, مسیر فایل‌ها). |
| **ایزوله‌سازی کدهای برنامه‌نویسی** | بلوک‌های کد (`pre`)، فرمول‌های ریاضی KaTeX و نمودارهای Mermaid همیشه به صورت دست‌نخورده و استاندارد چپ‌چین باقی می‌مانند. |
| **تایپ زنده و دوطرفه** | تغییر لحظه‌ای جهت متن در باکس تایپ پیام (ادیتور Lexical) به محض شروع تایپ فارسی یا انگلیسی. |
| **مصونیت در برابر آپدیت‌ها** | پایداری سه‌لایه (پلاگین، استارتاپ ویندوز، و پچر ASAR)؛ حتی پس از دریافت آپدیت جدید برنامه، پچ خودکار بازاعمال می‌شود. |
| **پشتیبان‌گیری و بازگشت ایمن** | ایجاد خودکار نسخه پشتیبان (`app.asar.rtl-backup.bak`) و امکان بازگردانی کامل به تنظیمات اولیه کارخانه با یک کلیک. |

## نصب سریع

### پیش‌نیازها
- سیستم‌عامل ویندوز ۱۰ یا ۱۱ (نسخه ۶۴ بیتی)
- [Node.js](https://nodejs.org) (نسخه ۱۸ به بالا)
- نرم‌افزار Antigravity 2.0

### مراحل نصب

ریپازیتوری را کلون کرده و فایل نصاب را اجرا کنید:

```cmd
git clone https://github.com/YOUR_USERNAME/antigravity-rtl.git
cd antigravity-rtl
bin\install.cmd
```

*یا با استفاده از npm:*

```bash
npm run apply
```

اگر نرم‌افزار Antigravity در حال اجرا باشد، پچ بلافاصله و **به صورت زنده** روی پنجره‌های فعال شما اعمال می‌شود (بدون نیاز به بستن و باز کردن مجدد برنامه).

## حذف و بازگردانی به حالت کارخانه

برای حذف کامل تغییرات و بازگردانی فایل اصلی نرم‌افزار:

```cmd
bin\uninstall.cmd
```

*یا با استفاده از npm:*

```bash
npm run revert
```
